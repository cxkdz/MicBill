# MicBill · 糯账

一款使用 Kotlin 开发的 Android 本地记账应用，提供收支记录、预算管理、账单导入和可自定义的主题界面。实验性的自动记账功能可识别支付通知与支付完成页，帮助生成记账草稿。

**当前版本：1.0.21 · Android 8.0（API 26）及以上 · 本机 OCR 需要 Android 14（API 34）及以上**

## 功能

| 功能 | 说明 |
| --- | --- |
| 日常记账 | 记录收入和支出，选择分类、支付方式、时间与备注，查看、编辑和删除账单 |
| 账单浏览 | 支持按日期横向翻页或按日期分组的竖向列表，可筛选收入、支出 |
| 统计与查询 | 查看分类占比、月度收支趋势，按日期范围查询明细与汇总 |
| 预算管理 | 设置月度总预算和分类预算，查看已用金额、剩余额度与每日消费建议 |
| 分类与规则 | 自定义收支分类及图标，按商户关键词设置自动归类规则 |
| 账单导入 | 微信支持 `.xlsx`、`.csv`；支付宝支持 `.xlsx`，导入前预览并跳过已有记录 |
| 备份与恢复 | 导出 JSON 格式的账本快照，恢复账单、分类、预算和归类规则 |
| 主题定制 | 内置墨影、紫烟、深海、樱织、暖昼、星夜六套主题，支持深色模式、自定义配色与前景、背景图片，以及雪花效果 |
| 自动记账（实验） | 识别支付通知，或通过可选的支付页面识别生成待确认记录 |

## 开始使用

安装 APK 后即可手动记账，无需注册账号。首页可添加收支记录，设置页可管理分类、预算、主题、导入与备份。

当前仓库保存源代码，APK 可按下方步骤自行构建；构建生成的安装包不会提交到 Git。

### 导入账单

1. 准备从微信或支付宝导出的账单文件，若文件经过压缩或加密，先解压为支持的格式。
2. 在「设置 → 数据导入」选择相应渠道与文件。
3. 查看解析预览，确认后导入。

当前导入入口会过滤转账、充值、提现等非消费类交易；两个渠道的过滤规则略有不同。导入适用于历史账单，与下述支付通知、支付页面识别使用不同的解析规则。

### 备份与恢复

在「设置 → 数据管理 → 备份与恢复」中导出或选择 JSON 备份文件。

**恢复会覆盖当前账单、分类、预算和归类规则，建议恢复前先导出当前备份。** 备份范围为账本业务数据，不包含自定义主题图片和自动记账待确认记录。

## 自动记账

入口位于「设置 → 功能 → 自动记账（实验）」。通知与页面内容会随支付应用版本和设备变化，识别结果需要核对。

### 支付通知

1. 开启「自动记账」，点击「通知使用权」，在系统设置中授权。
2. 按需授予悬浮窗权限、通知提醒权限，用于显示确认面板或提醒。
3. 收到可识别的支付通知后，在确认面板或「记录 / 待确认」中核对金额、收支方向、名称和分类，再确认入账。

已配置的通知来源包括微信、支付宝，以及农行、工行、建行、中行、招行、交行、邮储和云闪付。是否能够识别取决于应用包名和实际通知内容；银行通知缺少商户信息时需要补充名称。

默认逐笔确认。可选开启「分类明确的支付通知自动入账」；只有信息完整、商户明确、无重复嫌疑，且分类规则匹配到非「其他」分类的非银行支付通知，才会尝试自动入账。银行通知及信息不完整、疑似重复等情况仍需处理。**支付页面与本机 OCR 识别始终逐笔确认。**

### 支付结果页面识别

微信前台转账、收款时可能不会发送系统通知，可按需开启「支付结果页面识别」，并在系统无障碍设置中授权。

完成交易后打开单笔支付或转账详情，例如显示「对方已收款」「你已收款，资金已存入零钱」的页面，停留片刻，再到「记录 / 待确认」中处理。待收款、转账请求或未完成的页面不会作为已完成账单。

页面识别只处理受支持的微信、支付宝支付结果页，不会代替用户点击、收款或转账，也不会自动补齐全部历史交易。打开旧详情时，请核对账本中是否已经存在该笔记录。

### 本机识图备用

Android 14 及以上可手动开启「本机识图备用」。在支付结果页无法提供可读取文字时，应用会识别当前支付窗口的图像。

- 使用随应用打包的 ML Kit 中文模型，在设备端识别，无需下载在线模型。
- 截图仅在内存中临时处理，不保存、不上传。
- 无法确认完成状态、唯一金额或收支方向时，不直接生成已入账账单。
- 识图文字预览仅在内存中保留 5 分钟，需主动查看或复制。

### 没有生成记录时

先查看设置面板中的「通知监听连接」与「支付结果页面识别」状态。通知已授权但未连接时可尝试「恢复通知监听」；页面识别未连接时，可在系统无障碍设置中关闭后重新开启。

随后重新打开**已有的已完成交易详情**，无需再次付款或转账。在「记录 / 待确认 → 页面诊断」中查看识别原因，并可使用「复制页面诊断」反馈问题。普通页面诊断不包含 OCR 原文；有本次识图结果时，可另行选择「查看本次识图文字」。

若系统限制读取支付窗口，或页面格式尚未适配，可手动补记。识别出的草稿需要确认后才会计入账本。

## 数据与权限

账本保存在本机 SQLite 数据库中，偏好设置及自动记账记录保存在应用本地。核心记账功能无需登录；导入文件和导出位置由用户选择。

通知使用权开启后，已监听应用的通知标题和原文可能作为本地诊断保存，包括未识别成支付的通知。**关闭应用内「自动记账」只停止生成账单，通知诊断仍会记录；如需停止通知采集，请在系统设置中关闭通知使用权。**「记录所有通知来源」是另一个可选诊断开关，会保存来源包名和标题；标题缺失时可能使用正文片段。

| 权限或授权 | 用途 |
| --- | --- |
| 通知使用权 | 读取已适配来源的支付通知，解析记账候选 |
| 无障碍服务 | 可选读取受支持的支付结果页文字；本机识图开启后用于截取当前支付窗口 |
| 悬浮窗权限 | 在支付应用上方显示记账确认面板 |
| 通知提醒权限 | 发送待确认提醒，Android 13 及以上需系统授权 |
| 文件访问 | 选择账单文件、备份文件及自定义图片 |

自动记账相关能力按需开启，可随时关闭。应用已启用 Android 系统备份，实际备份行为由系统及设备设置决定。

## 构建与运行

### 环境

| 项目 | 版本 |
| --- | --- |
| JDK | 17 |
| Gradle | 8.5 |
| Android Gradle Plugin | 8.2.2 |
| Kotlin | 1.9.22 |
| Android SDK | API 34，Build Tools 34.0.0 |
| 最低运行系统 | Android 8.0 / API 26 |

可以使用 Android Studio 打开项目，也可以使用已安装的 Gradle 8.5。

**当前仓库仅包含 `gradle-wrapper.properties`，尚未包含 `gradlew`、`gradlew.bat` 和 `gradle-wrapper.jar`。** 以下命令使用本地安装的 `gradle`；在 Android Studio 中也需配置本地 Gradle 8.5。

```bash
git clone https://github.com/cxkdz/MicBill.git
cd MicBill
gradle :app:assembleDebug
```

请配置 `JAVA_HOME` 与 Android SDK 路径。Android Studio 可生成本机的 `local.properties`，也可自行设置 `ANDROID_HOME`。首次构建需要联网获取 Google Maven、Maven Central 与 JitPack 依赖。

Debug APK 输出位置：

```text
app/build/outputs/apk/debug/app-debug.apk
```

连接 Android 设备并启用 USB 调试后，可安装运行：

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

应用包名为 `com.billbook.app`。工程内部保留了 `BillBook` 命名，不影响 MicBill 的应用显示名称。

### 验证

运行 JVM 单元测试与 Android Lint：

```bash
gradle :app:testDebugUnitTest :app:lintDebug
```

单元测试覆盖支付通知解析、页面状态与金额提取、OCR 文本规范化、重复记录判断、草稿策略及页面采集规则。

设备端采集与 OCR 探针需 Android 14 及以上模拟器或设备：

```bash
gradle :app:assembleDebug :app:assembleDebugAndroidTest
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell am instrument -w com.billbook.app.test/com.billbook.app.autobill.AutoBillCaptureProbeInstrumentation
```

探针检查页面文字采集、可编辑与密码节点排除，以及本机 OCR 对完成和待收款状态的区分。它使用测试页面与图像，不执行真实支付。

## 代码结构

```text
app/src/main/java/com/billbook/app/
├── adapter/       列表、分类与日期分页适配器
├── animation/     动画与界面效果
├── autobill/      通知监听、页面采集、OCR、解析与草稿确认
├── db/            SQLite 数据库与数据访问
├── dialog/        设置、归类规则与自动记账记录面板
├── fragment/      设置、统计、预算与查询页面
├── model/         账单、分类与主题等数据模型
├── util/          账单导入、备份、主题与通用工具
└── view/          自定义视图

app/src/test/          JVM 单元测试
app/src/androidTest/   Android 设备端验证探针
app/src/main/res/      布局、图片、主题与其他资源
```

主要使用 Android Views / XML、ViewBinding、SQLite、MPAndroidChart、Apache POI 与 ML Kit 中文文字识别。
